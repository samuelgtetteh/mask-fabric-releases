# MASK FABRIC downloads

Installers for **MASK FABRIC**, your documents and AI in one private workspace.

- Website and the full app in your browser: https://maskfabric.ai
- Latest Windows installer: see [Releases](https://github.com/samuelgtetteh/mask-fabric-releases/releases/latest)

This repository holds installers only. The source code is not published here.

## Installing on Windows

1. Download `MASK-FABRIC-Setup.exe` from the latest release.
2. Run it. Windows may show "Windows protected your PC" because the installer is new; choose **More info**, then **Run anyway**.
3. FABRIC opens in its own window and works offline.

Problems or ideas: https://maskfabric.ai/feedback
